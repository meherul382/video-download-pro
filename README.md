# Video Download Pro

Paste. Check. Save.

A lightweight static web app for checking public YouTube, Facebook, and Instagram URLs and opening the original platform page.

## Deployment

This project is ready for Vercel. Import the GitHub repository and deploy as a static site. No build command or environment variables are required.

## SEO

The homepage includes a canonical URL, robots meta tag, Open Graph metadata, Twitter metadata, and WebApplication structured data. The sitemap is intended for the Vercel deployment URL.

## Usage policy

The site does not host or copy third-party videos and does not bypass DRM, private accounts, authentication, or platform restrictions. Use it only for content you own, have permission to save, or that the platform explicitly allows you to download.
